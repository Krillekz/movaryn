The workshop

Built for kits that have to work

Every reply respects the brief you wrote, the moves you already saved, and the limits of the game you're building for.

Constraints are requirements

Exact move counts, “no counters”, one-word names, a custom format — the project brief is sent with every message and treated as binding.

Sequences, not adjectives

Moves are described as start, action, contact, reaction and end, so a kit can be built from the text instead of interpreted from vibes.

Honest mechanics

If it can't verify that a game feature exists, Movaryn says so and offers a buildable alternative instead of inventing a node.

Names don't repeat

Every move name in the chat and project is kept as an avoid-list, so new suggestions don't quietly recycle last week's kit.

Art is a separate output

Concept art has its own brief, its own prompt and its own revisions. Generate it, copy the prompt for another tool, or build a card. Nothing fires automatically.

Yours, on your device

Conversations, projects and images live in local storage. Provider keys stay on your own server — there are no accounts and no telemetry.

How it works

From a sentence to a finished sheet

  1. 01

    Brief the character

    Name, game, theme, description and hard constraints. Add saved moves as the kit grows; the whole brief travels with every chat in the project.

  2. 02

    Shape the kit in chat

    Ask for a full kit or a single move. Replies render as move cards with copy buttons, a raw-text view and a regenerate option. Rejected ideas come back as different mechanics, not renames.

  3. 03

    Take it further

    Export Markdown, CSV or JSON. Build a 1600 × 1000 character card, or take the art prompt to Midjourney, DALL·E or Stable Diffusion. Re-import later without duplicates.

Prompt only

The same structured brief that generates art also hands back a finished prompt — aspect ratio included. Nothing is sent in that tab, so it works with no image provider at all.

Long conversations

Older turns are condensed in the background while recent ones stay verbatim. Constraints survive compression, and there is no app-imposed message cap.

FAQ

Short answers before you start

Setup, keys and the games this is built for — the practical parts, without a sales pitch.

How do I get set up?

Install Movaryn Setup or run the portable build. Neither bundles a key: create %APPDATA%\Movaryn\provider.env with at least AI_API_KEY, AI_BASE_URL and AI_MODEL, then launch the app.

For concept art, add IMAGE_API_KEY and IMAGE_MODEL, or use Cloudflare Workers AI with IMAGE_PROVIDER=cloudflare, IMAGE_ACCOUNT_ID and IMAGE_API_KEY.

Working from source instead? Node.js 20.19+ is required: npm install, copy .env.example to .env, then npm run dev.

Or run the browser build: open it and enter the URL of a Movaryn API you host. The page never holds a provider key.

Do I need my own provider key?

Yes for chat. There is no shared key and no hosted account. Without a key the app still opens, but AI features say they need configuration rather than pretending to work.

Keys are read by the local API server only — the page has no key handling and never sees one. Any OpenAI-compatible endpoint works: OpenAI, OpenRouter, Together, the Freebuff API, or a local server such as Ollama, LM Studio or vLLM.

The Prompt only tab assembles the image prompt from your brief and sends nothing, so it works with no image provider at all.

Which games is it built for?

Jujutsu Shenanigans (JJS), The Strongest Battlegrounds (TSB) and similar arena or battleground combat games. The brief has a free-form game field, so other combat games work as long as you describe their move rules.

Mechanics knowledge is not live. When Movaryn cannot verify that a Skill Builder feature exists, it says so and offers a buildable alternative instead of inventing one. It is not affiliated with Roblox or any game it mentions.

Where does my work live?

Conversations, projects, saved moves and generated images stay on your device. There are no accounts, no sync and no telemetry; exports give you an escape hatch. Only the messages, brief and images you send reach the provider you configured.
